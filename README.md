### 🚀 项目特色
‌脚本解释执行‌：用我自己定义的一些关键字来编写脚本，然后这个程序能读懂这些脚本并运行它们，比如执行打印、计算这些功能。
‌账户系统‌：支持注册、登录用户，还区分“普通用户”和“开发者”权限。
‌付费/订阅功能‌：设计了“编码 pro 订阅”的概念，用户可以获取和激活订阅码来解锁高级功能。
‌代码仓库 (Git) 功能‌：自己模仿 Git 做了简单的代码仓库，可以创建仓库、添加代码文件、从中提取文件。
‌变量与函数‌：支持多种数据类型的变量（字符串、数字、布尔值），支持定义和调用自定义函数。
‌条件与循环（部分实现）‌：代码里看到了 <如果>、<循环导入> 等结构的设计，用于控制程序流程。
‌模块导入‌：写的脚本可以导入其他文件作为“模块”，方便代码复用和组织。
### 📁 主要文件说明
‌解释器.py‌：这是程序的“大脑”，是一个交互式的主程序文件。主要功能有：

启动交互界面 (>>>) 等待命令。
负责加载账户、激活码、仓库列表等用户数据。
处理用户账户相关的命令，如‌注册（）、登录（）、查看账户信息（）、创建 Git 仓库（）、将文件添加到 Git 仓库（）‌ 等。
加载用户指定的代码文件，启动真正的“脚本解释”执行过程。
‌模块识别器1.py 和 模块识别器2.py‌：它们是解释器的“执行引擎”。负责解读和运行用户编写的脚本文件。

它们会一行行地解析脚本，理解像 打印（内容）、赋值、整数（字符串）、定义、+ - * / 计算、随机抽取变量并打印（） 等复杂的代码结构。
它们实现了变量的查找、函数定义、导入 模块、条件判断等核心功能。
‌自定义函数解释器.py‌：从 解释器.py 和模块识别器的代码看到需要导入这个文件（但目前内容没提供）。它应该负责执行“自定义函数定义”和“函数调用”，是解释复杂逻辑（如函数传参、返回值）的关键部分。

‌环境变量文件‌：程序运行时会读取和修改本地的文本文件来持久化存储信息。

环境变量/账户列表.txt：存储注册的账户信息。
环境变量/激活码列表.txt：存储已生成但未被使用的激活码。
环境变量/Git仓库列表.txt：存储用户创建的仓库信息。
环境变量/Git仓库储存/：文件夹，里面 .txt 文件是每个仓库存放代码内容的地方。
### 💡 我能用这个项目做什么？
‌编写自己的小程序脚本‌：
脚本可以用简单的自定义语法编写，比如 打算、答案赋值42 或 打印（‘你好世界’）。
放到某个文件夹，然后在 解释器.py 启动时输入文件路径，就能运行它！
‌管理你创建的脚本‌：
可以先‌注册‌一个账户，登录后就能用‌创建 Git 仓库（）‌ 创建一个库。
然后用‌将文件添加到 Git 仓库（）‌ 把写好的脚本保存进去。
想要分享或保存备份时，可以使用‌从 Git 仓库中提取文件（）‌ 取出来。
‌学习解释器原理‌：
这份代码实现了解释一个指令（词法、语法分析）、管理变量作用域、执行基本运算和函数调用的完整流程，对理解Python编程和程序运行原理很有帮助。
### 🔧 如何开始使用？
运行 python 解释器.py。
看到 >>> 提示符后，可以输入 注册（） 创建一个自己的账户（需要输入用户名、密码和系统给的激活码，初始激活码见程序第一行打印出的内容）。
‌登录（）‌ 自己的账户，这样后续才能使用仓库相关的功能。
准备好自己的脚本文件，输入文件名（比如 demo.abc，假设你的脚本都是 .abc 结尾）来运行看看。
探索其他高级命令，如‌获取订阅编码 pro（）、激活订阅编码 pro（）‌ 等。
### ✨ 代码亮点
‌函数式思维‌：设计了很多“功能”封装成命令，比如 输入（）、计时——开始/结束（）、随机数、整除（），这是典型的面向过程/函数式程序设计思路。
‌变量作用域处理‌：代码中出现了 d1 (存储全局变量) 和 d2 (存储自定义函数信息) 等字典来追踪脚本中的各种名字和值。
‌错误处理‌：有很多代码分支（比如 如果...否则...继续、打印‘名字错误’）来处理编程中可能发生的错误，能让程序稳定一些。
‌清晰的模块分工‌：主交互引擎 解释器.py 与核心解释引擎 模块识别器.py 分工明确，便于修改和维护。
